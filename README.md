# SonicAnalyzer-CPP

Una herramienta de análisis de audio de alto rendimiento para Windows construida en C++.

## 🚀 Características (En desarrollo)
* **Detección de BPM:** Análisis de tempo mediante algoritmos de transitorios.
* **Key Estimation:** Identificación de la tonalidad musical.
* **Loudness Metering:** Medición de LUFS (estándar ITU-R BS.1770-4).
* **Visualización de Onda:** Renderizado gráfico con alertas rojas de saturación (clipping).

## 🛠️ Tech Stack
* **Lenguaje:** C++20
* **Framework:** JUCE (Audio & GUI)
* **IDE:** Visual Studio 2022
* **Plataforma:** Windows 10/11
